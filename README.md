# Homework 1 — Online Shoppers Purchasing Intention

Цель проекта — построить модель бинарной классификации, которая по характеристикам пользовательской сессии предсказывает, завершится ли она покупкой (`Revenue=True`).

## Датасет

Используется датасет **Online Shoppers Purchasing Intention**.

Исходные данные содержат:

- 12 330 пользовательских сессий;
- 17 признаков;
- целевую переменную `Revenue`;
- числовые, категориальные и логические признаки.

После удаления 125 полных дубликатов осталось 12 205 наблюдений.

Положительный класс составляет около 15,6% выборки, поэтому при оценке моделей основное внимание уделяется не только Accuracy, но и метрикам:

- Average Precision;
- ROC-AUC;
- Precision;
- Recall;
- F1.

## Что выполнено

В работе проведены:

- первичная проверка данных;
- удаление полных дубликатов;
- отделение финальной тестовой выборки до EDA;
- исследовательский анализ данных;
- анализ дисбаланса классов;
- анализ распределений и корреляций;
- разделение признаков на числовые и категориальные;
- стандартизация числовых признаков;
- one-hot кодирование категориальных признаков;
- объединение преобразований и моделей в `Pipeline`;
- сравнение моделей на одинаковых фолдах кросс-валидации;
- подбор гиперпараметров;
- проверка шести ML-гипотез;
- встроенный отбор признаков с помощью L1-регуляризации;
- финальная оценка выбранной модели на тестовой выборке;
- анализ ошибок с помощью confusion matrix.

## Модели

В работе сравнивались:

- `DummyClassifier`;
- `LogisticRegression`;
- `DecisionTreeClassifier`.

Основной метрикой выбора модели была **Average Precision**, поскольку целевой класс несбалансирован.

## Проверенные гипотезы

1. Logistic Regression покажет более высокий Average Precision, чем базовое дерево решений.
2. Ограничение сложности дерева уменьшит переобучение и повысит качество на валидации.
3. L1-регуляризация позволит обнулить значительную часть коэффициентов без существенной потери качества относительно L2.
4. `class_weight="balanced"` повысит Recall положительного класса.
5. Новый признак `AvgProductDuration` повысит качество Logistic Regression.
6. Удаление `PageValues` заметно ухудшит качество модели.

### Результаты гипотез

- Гипотеза 1 подтвердилась.
- Гипотеза 2 подтвердилась.

- Гипотеза 4 подтвердилась.
- Гипотеза 5 не подтвердилась.

## Защита от утечки данных

В работе соблюдены следующие правила:

- финальная тестовая выборка отделена до EDA;
- при разделении использован `stratify=y`;
- тестовая выборка не использовалась для проверки гипотез и подбора гиперпараметров;
- стандартизация и кодирование выполнялись внутри `Pipeline`;
- преобразования обучались отдельно на тренировочной части каждого фолда;
- все сравнения проводились на одинаковых фолдах кросс-валидации;
- тестовая выборка использовалась только для финальной оценки выбранной модели.

## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone <https://github.com/andreym1234/homework-1-online-shoppers>
cd homework-1-online-shoppers
```

2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать окружение.

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

4. Установить зависимости:

```bash
pip install -r requirements.txt
```

5. Убедиться, что датасет находится по пути:

```text
data/online_shoppers_intention.csv
```

6. Запустить JupyterLab:

```bash
jupyter lab
```

7. Открыть `research.ipynb` и выполнить все ячейки сверху вниз.
